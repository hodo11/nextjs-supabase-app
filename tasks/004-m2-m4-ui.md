# Task 004: M2~M4 화면 UI 완성 (정산·카풀·출석, 더미 데이터)

## 개요

정산, 카풀, 출석 체크, 출석 현황 화면과 홈의 미납 정산 섹션을 더미 데이터로 완성한다.

- 기능 ID: F010~F017 (화면)
- 선행 Task: 001, 002, 003

## 관련 파일

- `app/(app)/events/[eventId]/settlement/page.tsx`, `components/settlement/settlement-panel.tsx`
- `app/(app)/events/[eventId]/page.tsx`: 정산 버튼, 카풀, 출석 영역 합침
- `components/event/{ride-panel,attendance-panel}.tsx`
- `app/(app)/groups/[groupId]/attendance/page.tsx`
- `app/(app)/home/page.tsx`: 내야 할 정산 섹션
- `lib/validations/settlement.ts`: `calcPerPerson` (10원 단위 올림)

## 수락 기준

- [x] 정산: 주최자 입력 폼, 참석자 수·1인당 금액 미리보기, 생성 확인 다이얼로그
- [x] 정산: 미납·확인 대기·완료 집계, 입금 확인 체크, 메일 재발송 버튼, 참여자 "송금했어요"
- [x] 이벤트 상세의 정산 버튼은 종료된 이벤트에서만 노출
- [x] 카풀: 차량 카드(남은 좌석), 등록·수정 폼(좌석 1~8), 탑승 신청·취소, 대기/승인/거절 배지, 승인·거절 버튼(운전자·주최자)
- [x] 출석 체크(주최자): going 응답자 목록, 시작 전 비활성화 안내
- [x] 출석 현황: 출석 횟수·출석률 정렬 표, 분모 0이면 `-`, 참여자는 본인 행만
- [x] 홈 "내 할 일"에 미납 정산 섹션
- [x] Playwright MCP로 375px 스크린샷 확인 (`tasks/screenshots/004-*.png`)

## 구현 메모

- 상태 배지는 색뿐 아니라 아이콘·텍스트를 함께 쓴다.
- 정산 금액 경계값: 30001원 / 3명 → `ceil(30001 / 3 / 10) * 10 = 10010원`.
- 더미 기준 사용자: 주최자 보기 `u1`(정산 완료), 참여자 보기 `u2`(정산 "확인 대기").
- 완료된 이벤트는 수정 링크를 숨기고 정산 버튼을 보여 준다.
