## 구현 메모

- Cache Components의 즉시 이동 검증 때문에 각 페이지는 `params`/`searchParams`를 읽는 본문을 `Suspense`(+`PageSkeleton`)로 감싼다.
- 헤더의 `PreviewToggle`과 `AppNav`가 `?as=member`를 유지한다. Phase 2에서 제거한다.
- 화면 확인용 서버는 `NEXT_PUBLIC_SUPABASE_*`를 빈 문자열로 주어 proxy 검사를 생략한 상태로 띄웠다(소스 변경 없음).
