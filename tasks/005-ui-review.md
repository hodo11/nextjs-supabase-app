# Task 005: UI 검토·보완 (Playwright MCP 스크린샷 리뷰)

## 개요

Phase 1에서 만든 전체 화면을 Playwright MCP로 점검하고 개선점을 반영한다. 이 Task가 끝나면 사용자 확인을 받은 뒤 Phase 2를 시작한다.

- 기능 ID: F001~F017 (화면)
- 선행 Task: 003, 004

## 검토 환경

- `npm run dev`를 `NEXT_PUBLIC_SUPABASE_URL`/`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`를 빈 문자열로 주어 실행했다. `hasEnvVars`가 `false`가 되어 proxy 검사가 생략되므로 이 검토 환경에서는 모든 프로토타입 화면이 공개 상태다. 실제 `.env.local`이 설정된 환경에서는 `/home` 등이 `/auth/login`으로 리디렉션되는 것을 확인했다(HTTP 307).
- 기준 시각은 2026-10-20 12:00 KST로 고정(`lib/dummy/clock.ts`).

## 핵심 플로우 단계 수

- 카톡 링크 진입: 초대 링크 → "참여하기"(1) → 모임 목록 → 모임(2) → 이벤트(3) → RSVP(4). 개선안 적용 시 "참여하기"(1) → 모임 상세에서 이벤트(2) → RSVP(3).
- 주최자: 모임(1) → 이벤트 만들기(2) → 저장(3). 초대 링크 복사는 모임 상세에 바로 노출되어 추가 이동이 없다.

## 접근성 점검

- 키보드 포커스 순서는 DOM 순서(헤더 → 본문 → 하단 내비)를 따른다. 카드 링크와 버튼에 포커스 링이 보인다.
- 폼 필드는 `FormLabel`로 라벨이 연결되어 있고, 아이콘 전용 버튼에는 `aria-label`이 있다.
- 상태 배지(예정/응답 마감/지난/취소됨, 대기/승인/거절, 미납/확인 대기/완료)는 텍스트 라벨과 아이콘을 함께 쓰며, RSVP 집계는 색 + 숫자 + 라벨로 표시한다.
- 라이트·다크 모드에서 본문과 보조 텍스트를 읽을 수 있음을 눈으로 확인했다(정식 대비 측정은 하지 않음).
